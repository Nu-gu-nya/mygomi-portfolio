# MyGomi — 외국인 거주자를 위한 쓰레기 분리배출 지원 웹앱 (담당 파트 정리)

**한국어** | [日本語](README.md)

> 팀 개발 프로젝트 중 **제가 담당한 부분**을 정리한 페이지입니다.
> 소스 코드는 팀 레포지토리에 있습니다 (페이지 하단 링크 참고).

## 개요

일본의 쓰레기 배출 규칙은 지자체마다 다르기 때문에, 일본어가 익숙하지 않은 외국인 거주자에게는
"이 쓰레기를 언제, 어떻게 버려야 하는지" 찾아보는 것 자체가 부담입니다.

MyGomi는 사는 지역을 설정하기만 하면 **수거일 캘린더·품목별 배출 방법·동네 중고 나눔**을
하나의 서비스에서 확인할 수 있는 웹앱입니다.

## 구성·기간

| 항목 | 내용 |
|---|---|
| 형태 | SCIT 48기 팀 프로젝트 |
| 인원 | 4명 (백엔드 2명·프론트엔드 2명) |
| 기간 | 2026년 1월 ~ 3월 (약 2개월) |
| 내 역할 | 기획 (팀 전원 공동) / 백엔드 |

## 담당한 내용

### 기획·설계 (팀 전원 공동)

주제 선정부터 개발에 들어가기까지의 설계 과정을 역할 분담 없이 팀원 전원이 함께 진행했습니다.

- 주제 선정 (외국인 거주자의 쓰레기 배출 부담이라는 문제 설정)
- 기능 정의서·요구사항 정의서 작성
- 개발 기능 단위로 Markdown 문서화
- 쓰레기 분리배출 데이터 수집 규칙 수립, 데이터 수집, 전처리

### 백엔드 (개인 담당)

사용자가 로그인한 뒤 자기 주소 주변의 나눔 게시글을 지도에서 보기까지의
**백엔드 데이터 흐름**을 담당했습니다.

```
① 인증(JWT)  →  ② 주소 기반 지도 API  →  ③ 게시글 CRUD·이미지 저장  →  ④ 지도 API와 게시글 데이터 연동
```

| # | 기능 | 내용 |
|---|---|---|
| ① | 회원가입·로그인 | JWT를 이용한 인증 구현 |
| ② | 주소 기반 지도 API | 사용자가 설정한 주소를 기준으로 주변 데이터를 반환하도록 API 수정 (거리 계산 로직은 팀원 구현을 활용) |
| ③ | 나눔 게시글 | 게시글 작성·수정·삭제와 사진 저장 기능 |
| ④ | 지도와 게시글 연동 | 지도 API가 실제 게시판 데이터를 반환하도록 연결 |
