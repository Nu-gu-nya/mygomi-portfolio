# MyGomi — 外国人居住者向けゴミ分別支援 Webアプリ（担当分のまとめ）

[한국어](README.ko.md) | **日本語**

> チーム開発プロジェクトのうち、**私が担当した部分**をまとめたページです。
> ソースコードはチームのリポジトリにあります（ページ下部のリンク参照）。

## 概要

日本のゴミ出しルールは自治体ごとに異なり、日本語に不慣れな外国人居住者には
「このゴミはいつ、どう出せばいいか」を調べること自体が負担になっています。

MyGomi は、住んでいる地域を設定するだけで **収集日カレンダー・品目ごとの出し方・近所での不用品の譲り合い** を
ひとつのサービスで確認できる Web アプリです。

## 担当した内容

### 企画・設計（チーム全員で実施）

主題選定から開発に入るまでの設計工程を、メンバー全員で分担せずに進めました。

- 主題選定（外国人居住者のゴミ出しの負担という課題設定）
- 機能定義書・要件定義書の作成
- 開発機能単位での Markdown 文書化
- ゴミ分別データの収集ルール策定、データ収集、前処理

### バックエンド（個人担当）

ユーザーがログインしてから、自分の住所の周辺にある譲り合い投稿を地図で見るまでの
**バックエンドのデータの流れ**を担当しました。

```
① 認証（JWT）  →  ② 住所ベースの地図API  →  ③ 投稿CRUD・画像保存  →  ④ 地図APIと投稿データの連携
```

| # | 機能 | 内容 |
|---|---|---|
| ① | 会員登録・ログイン | JWT を用いた認証の実装 |
| ② | 住所ベースの地図API | ユーザーが設定した住所を基準に周辺データを返すよう API を修正（距離計算のロジックはチームメンバーの実装を利用） |
| ③ | 譲り合い投稿 | 投稿の作成・編集・削除と、写真の保存機能 |
| ④ | 地図と投稿の連携 | 地図 API が実際の掲示板データを返すように接続 |
